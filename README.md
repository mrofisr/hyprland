# hyprland

My Hyprland configuration, written in Lua (`hyprland.lua` with split-out modules)
plus `hypridle` and `hyprlock`.

```
hyprland.lua   # entry point: general, decoration, misc
apps.lua       # window rules + autostart apps
binds.lua      # keybinds
input.lua      # input devices (kb layout, touchpad, ...)
colors.lua     # palette
overrides.lua  # last-load tweaks
hypridle.conf  # idle daemon
hyprlock.conf  # lock screen
config/k4.lua        # k4 bar integration (generated — do not edit)
config/k4-theme.lua  # k4 HyprTheme (generated — do not edit)
```

## Install

Clone anywhere and symlink into `~/.config/hypr`:

```sh
git clone https://github.com/mrofisr/hyprland ~/repos/hyprland
mkdir -p ~/.config/hypr
ln -s ~/repos/hyprland/*.lua ~/repos/hyprland/*.conf ~/.config/hypr/
ln -s ~/repos/hyprland/config ~/.config/hypr/config
```

Requires a recent Hyprland with Lua config support, plus `hypridle` and
`hyprlock` for the idle/lock files.

## Notes

- `config/k4.lua` and `config/k4-theme.lua` are generated by the k4 bar's
  installer and get rewritten on update — edit your own config instead of
  these.
- `hyprlock.conf` references a wallpaper at
  `~/.local/share/wallpapers/makkah-1.png`; point it at your own image.
